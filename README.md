# Trading Terminal

React 19 + TypeScript + Vite + TanStack Router. Клиентское приложение (Web Worker, localStorage, WebSocket, график lightweight-charts), Supabase — персистентность и edge-прокси.

Команды: `npm run dev`, `npm run build`, `npm test`, `npm run typecheck`.
Переменные окружения: см. `.env.example`.
Бэктесты и аудиты (`backtest/`) запускаются в GitHub Actions; их `backtest/output` в репозиторий не входит.
